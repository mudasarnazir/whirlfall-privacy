# Whirlfall Privacy Policy

A minimal static GitHub Pages site for Whirlfall's privacy policy. It uses one standalone
HTML file with no frameworks, build process, or external dependencies.

## Publish with GitHub Pages

1. Create a public GitHub repository named `whirlfall-privacy`.
2. Push this repository to the `main` branch.
3. Open the repository on GitHub and go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then choose **Save**.

GitHub will publish the policy at:

`https://mudasarmarth.github.io/whirlfall-privacy/`

Allow a few minutes for the first deployment. Use the published HTTPS URL for Whirlfall's
privacy-policy setting and in App Store Connect.
